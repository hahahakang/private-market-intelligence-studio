# 一级市场资本情报系统 · 公开安全快照

本仓库仅承载 GitHub Pages 静态展示文件，公开站只展示经过字段白名单导出的聚合快照。

## 公开边界

- 不包含 IF 五分钟或日线原始行情、指数历史 CSV/Parquet、官方 factsheet PDF。
- 不包含 iFinD/CTP/API Token、账号、密钥、本机路径、服务端代码或刷新脚本。
- 不包含项目名称、项目 ID、创始人、融资/估值/退出/减值事件、现金跑道或投委会底稿。
- 不公开逐日因子序列、相似历史日期、审计文件路径或数据源 URL。
- 页面仅展示当期聚合市场状态、7 组指数代理汇总、4 项一级市场公开代理与非项目级人工复核范围。
- 4 项公开代理分别为融资环境、估值环境、退出窗口与减值压力；不冒充项目融资成功率、一级估值变化率、退出概率或实际减值率。

公开快照不构成交易信号、项目评级或自动化投决。
